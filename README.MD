## 📌 Project Overview

The goal of this project is to create a professional pricing section containing multiple subscription plans.

The project goes beyond a basic pricing table by adding:

- Monthly / yearly billing
- Dark / light mode
- Interactive comparison table
- Responsive design
- Hover effects
- Toast notifications
- Local storage
- Accessibility improvements

---

## ✨ Features

### 💰 Pricing Plans

The project contains three pricing plans:

1. Starter
2. Pro
3. Business

The **Pro** plan is highlighted as the most popular plan.
